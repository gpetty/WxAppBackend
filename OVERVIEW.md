# Weather Window App — Backend Overview

The backend is responsible for keeping a fresh, queryable snapshot of weather forecast data available at all times. Every hour, it automatically downloads the latest National Blend of Models (NBM) forecast issued by NOAA, which covers the entire continental United States and looks up to eleven days ahead. That raw forecast data is processed and organized on disk so that when a user's device asks "what is the weather going to be at my location, hour by hour?", the server can respond almost instantly with a clean time series of weather variables — things like temperature, wind speed, cloud cover, and solar radiation. The backend also computes a handful of derived conditions, such as wind chill and sun elevation, that are not provided directly by NOAA but are needed for the app's activity-suitability logic. From the app's perspective, the backend is simply a reliable, always-current weather data service: send it a location, get back a forecast.
